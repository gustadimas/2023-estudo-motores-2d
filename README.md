# Estudo de Motores 2D

Feito em mar/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Estudo das primeiras aulas de motores 2D. Tem o personagem andando (`PlayerMove.cs`), uma arma que atira (`Gun.cs` e `Bullet.cs`), moedas pra coletar (`CoinCollector.cs`) e o `AudioManager` que acabei levando pra vários projetos depois.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.6f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
